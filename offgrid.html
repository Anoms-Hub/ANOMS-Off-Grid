OffGrid

A minimal, neon‑forward landing page built without a traditional grid system. Floating blocks, clean rhythm, and AO‑aligned glow harmonics.

What “Off‑Grid” Means

This layout avoids CSS grid and flexbox for the main structure. Instead, it uses natural document flow and floating containers to create a freeform, breathable rhythm.

Why Use It

Off‑grid layouts feel organic, less mechanical, and more expressive. They’re perfect for mood‑driven pages, lore entries, or experimental AO micro‑sites.

Where It Fits in AO

Use this pattern for standalone lore drops, hidden pages, or experimental prototypes that don’t need the full AO layout system.
