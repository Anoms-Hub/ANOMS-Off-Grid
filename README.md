## ⚡ What Is ANOMS-Off-Grid?

ANOMS-Off-Grid is the **creative sandbox** for the Anom Originals ecosystem. This is where wild ideas live before they become real features — experimental prototypes, AI explorations, half-baked concepts, and archived experiments that didn't make the cut (but might come back someday).

Nothing here is production-ready. Everything here is valuable.

---

## 📂 Folder Structure

```
ANOMS-Off-Grid/
├── experiments/    # 🔬 Active experiments and proofs of concept
├── prototypes/     # 🛠️ Working prototypes and demos
├── ai-tests/       # 🤖 AI/ML explorations and generated content tests
├── scrapbook/      # 📓 Ideas, sketches, inspiration, and notes
├── archive/        # 🗃️ Completed or shelved experiments
└── README.md
```

---

## 🗂️ What Goes Where

| Folder | What It's For | Examples |
|--------|--------------|---------|
| **experiments/** | Active tests and explorations | New reward systems, layout concepts, interaction patterns |
| **prototypes/** | Functional demos that prove an idea works | Clickable mockups, mini-apps, feature previews |
| **ai-tests/** | AI and machine learning explorations | Generated art tests, prompt experiments, model outputs |
| **scrapbook/** | Raw inspiration and unstructured ideas | Mood boards, screenshots, voice notes, brainstorms |
| **archive/** | Completed or paused experiments | Past prototypes, retired concepts, post-mortems |

---

## 🔄 Lifecycle of an Experiment

```
💡 Idea → scrapbook/
    ↓
🔬 Testing → experiments/
    ↓
🛠️ Working demo → prototypes/
    ↓
✅ Approved → Moves to the appropriate production repo
    or
🗃️ Shelved → archive/
```

---

## 🎯 Guidelines

- **No idea is too weird** — this is the place for creative risk
- **Document your experiments** — even failed ones teach us something
- **Label clearly** — use descriptive folder/file names so others can find things
- **Don't leave secrets** — no API keys, tokens, or credentials in this repo
- **Graduate winners** — when something works, move it to the right production repo
